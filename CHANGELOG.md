# История версий

Версия имеет вид `YY.MM.DD.HHMM` и показывается в приложении вместе с версией Xray.
В `pubspec.yaml` дополнительно есть монотонный `versionCode` (минуты с 2020-01-01),
поэтому порядок сборок не ломается при переходе через сутки.

Каждый релиз — аннотированный git-тэг `v<версия>[-alpha|beta]`. Откат делается
через тэг, а не через удаление коммитов.

## [26.11.24.1430] — третья альфа

- Лицензия собственного кода заменена с MIT на Curie Source-Available License 1.0:
  исходники доступны для изучения и личного пользования, публикация и коммерческое
  использование — только с разрешения. Сторонние компоненты описаны в
  `THIRD_PARTY_NOTICES.md`. Снимки кода, уже опубликованные под MIT (до этой версии),
  остаются MIT — отозвать выданную лицензию нельзя. В «Настройках» исправлена
  подпись: вместо «Curie — MIT» теперь указана source-available лицензия.
- Исправлена атрибуция коммитов: все они переписаны на `WaylandX11`, GitHub больше
  не показывает постороннего контрибьютера.
- Интерфейс главного экрана уплотнён: время подключения и скорость перенесены в
  большую кнопку, «Проверить» — в шапку. Обновление подписки и пинг вынесены в
  отдельные кнопки рядом с названием (порядок: название → обновление → пинг →
  шестерёнка); у пинга появился спиннер, шестерёнка оставила только ссылку и
  управление подписками.
- Исправлены стрелки ↑/↓: опрос метрик больше не сбивается событием `connecting`,
  которое приходило уже после запуска опросчика. Старт теперь привязан к
  `connected`, а формат `/debug/vars` Xray 26.x зафиксирован тестом.
- Починен GitHub Actions: убран BOM из `core.lock.json`, добавлена проверка SHA-256
  ядра, лишняя установка NDK удалена (в проекте нет своего нативного кода).
- Добавлена проверка обновлений GitHub без Google Play: «Настройки → О приложении →
  Проверить обновления». Приложение сравнивает штамп версии и предлагает открыть
  страницу релиза или скачать APK под архитектуру устройства (`universal`/`arm64`/
  `arm32`/`x64`).
- Публикация стала явной: `tag-release.ps1` без `-Publish` только проверяет тэг,
  а workflow релиза прикрепляет сразу четыре APK вместо одного.

## Как откатиться

```powershell
# Посмотреть доступные точки восстановления
git tag -l

# Собрать старую версию в отдельной ветке, не трогая main
git checkout -b rollback/v26.11.24.0952 v26.11.24.0952
cd app; flutter build apk --debug

# Если нужно отменить конкретный коммит в общей истории — revert, а не reset
git checkout main
git revert <hash>
```

Git хранит всю историю локально; после добавления remote и `git push --follow-tags`
те же тэги и коммиты появятся на GitHub.
